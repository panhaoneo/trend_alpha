# 景气趋势选股框架：静水2008 × 欧奈尔 CANSLIM（蒸馏版）

> 由两份材料蒸馏合成，用于指导 `projects/trend_alpha/run.py` 的每日自动选股：
> - 材料A：《静水2008 投资问答集》（本地收藏资料，未随仓库分发）
> - 材料B：威廉·欧奈尔《笑傲股市》(第4版, CAN SLIM 法则)（本地收藏资料，未随仓库分发）
> 版本：v1.0（2026-09-08）

## 0. 一句话方法

**盯住当下景气度最高行业中业绩集体超预期、股价创一年新高的核心受益公司（核心α），
在财报期（1/4/7/8/10月）用"利润+营收双高增"过滤全市场，只留强者；入场等回调分仓，错了止损，对了持盈。**

## 1. 材料A：静水2008 方法论要点（趋势投资 / 景气跟随）

1. **行业先行**：先问"当下时代最景气行业是什么"——特征：业绩批量超预期（板块效应）、政策倾斜、社会关注度高、有实打实业绩支撑；不要用主观预判替代对当下客观景气的跟随。
2. **只做核心α**：景气行业中最核心受益、市场资金最认可的公司，强者恒强；回避低位杂毛/垃圾股（业绩增速下滑、股价创新低、竞争力变差）。
3. **财报是抓手**：财报期批量读财报，量化锚点 **营收与利润同比增速 > 40%**；关注"供不应求、量价齐升、新品放量、市场拓展"等表述。
4. **新高是确认**：股价创一年/历史新高，代表趋势与市场共识确认；趋势跟随的核心是"看见"而非"预测"。
5. **回调是买点**：创出新高的核心α，等回调时分仓分批介入（胜率来自景气行业无数次小回调），对了死拿（让利润奔跑），错了坚决砍掉（截断亏损）；止损不止盈。
6. **顺势与大盘**：牛市参与主线，熊市等待；不预判拐点、不猜底。
7. **排除项**：ST/退市风险、增速下滑无拐点、股价创新低、无新产品/新市场想象空间、非行业核心、基本面恶化仍装死。

## 2. 材料B：欧奈尔 CAN SLIM 七要素（笑傲股市第4版）

| 要素 | 原始规则（要点） | 本框架量化代理 | 数据源 |
|---|---|---|---|
| **C** 当季盈利 | 当季每股收益同比≥18-25%（越大约好，50%+为佳）且加速；当季营收同比≥25% | **三率门槛**: 主报告期 营收同比≥30% / 归母净利同比≥40% / EPS同比≥30%（API暂无EPS字段, 以归母净利同比代理）; 前一报告期净利≥40% 验证持续性 | `/api/a-share/financials/indicators` |
| **A** 年度增长 | 年度EPS增长≥25%（近3年复合更佳）；ROE≥17% | 上一财年净利同比≥25%（可选开关）；加权ROE≥15%（计分） | 同上（年报报告期） |
| **N** 新高/新事物 | 买点＝股价自基部放量突破（带柄茶杯等形态中轴点）；伴随新产品/新服务/新管理层 | 距52周高点≤5%（新高强势）或≤15%（强势区） | 日K历史（`prices/historical`） |
| **S** 供需/量能 | 突破需成交量放大40-50%以上；关注回购、流通盘 | 放量比 = 近5日均量/近60日均量 ≥1.5（计分）；流通市值下限过滤微盘 | 日K volume |
| **L** 领军股 | 股价相对强度RS≥80（排名前20%）；只买行业内前2名 | RS代理 = 250日相对沪深300超额收益 + 全池250日收益百分位≥80（计分） | 日K + 沪深300日K |
| **I** 机构认同 | 近几季机构增持（优质基金持股） | ⚠️ 无持股数据：以流通市值≥30亿、成交额≥3000万近似"机构可参与度"，其余人工核验 | auction快照（float_market_cap） |
| **M** 大盘方向 | 大盘中期趋势向上才买入（3/4市场指数确认）；下跌市持币 | 上证/沪深300/创业板指 ≥2/3 收盘站上 MA50（中期）与 MA200（长期） | 指数日K |

## 3. 统一量化筛选规则（v1.0，`config.py` 可调）

**候选池**：全A − ST − 北交所(.BJ) − 科创板(688)（可配置），剔除无财务数据新股。

**硬条件（全部满足才入池）**：
1. 主报告期 `REPORT_MAIN`(默认2026-2中报) **三率门槛**：营收(销售)同比≥30% 且 归母净利同比≥40% 且 EPS同比≥30%
   （EPS同比: 无每股收益增速字段时以归母净利同比代理，`REQUIRE_EPS` 可关）
2. （默认开）前一报告期 `REPORT_PREV`(2026-1) 净利同比 ≥ 40%（双期确认，对应"持续高增而非单季脉冲"）

**计分项（0-100，权重见下表）**：
ROE(中报加权,≥15%质量分)、距52周高点（越近越高分）、RS百分位、放量比、行业热度（见§4）。

**质量指标列（计算化展示，对应旧人工清单第2项）**：
- `毛利Δ`：毛利率同比变化（百分点，`REPORT_CMP` 同期对比）
- `净现比%`：经营现金流净额÷净利润（`net_profit_cash_content`）
- `现金质量`：净现比≥100%且现金营运指数≥0.8→优 / ≥60%→良 / ≥30%→一般 / 其余→差

**硬条件以上但缺技术数据（次新/停牌）**：不参与分组，单独列出待观察。

## 4. 行业热度（板块效应量化）

- 行业口径：同花顺一级行业（881xxx，约90个）；**成分缺失的股票回退二级行业(884xxx, 名称标注·二级)**；仍无归属记"未分类"且**不计为热行业**
- 热度 = 该行业"过线家数"（中报利润+营收双达标）≥5 且 行业平均净利增速≥40% → **热行业**（"未分类"永不热）
- 排序输出：过线家数、平均增速、板块近60日涨幅
- 语义：板块内批量超预期＝景气上行验证（静水"板块效应"，CANSLIM 的行业前2）

## 5. 大盘方向（M）

- 取 上证指数、沪深300、创业板指 收盘价 vs MA50/MA200
- `market_up`：≥2/3 指数站上 MA50（默认仅提示；`HARD_M_FILTER=True` 时可作为硬开关直接空仓）
- 大盘弱市时报告顶部明确警示（静水：熊市等待，不猜底）

## 6. 输出分组语义（怎么用）

| 分组 | 定义 | 使用方法 |
|---|---|---|
| **A 景气核心α** | 热行业 + 距52周高点≤15% + 收盘>MA150 | 首选清单：行业景气已被市场验证的强者，回调节奏中跟踪 |
| **B 一年新高/接近新高** | 距52周高点≤5% | 突破/新强势确认（欧奈尔突破点附近），谨慎追高、等回调 |
| **C 回调观察** | 距高点15%-35%，仍在MA150上方 | 静水式回调买点区：分仓分批介入的主要观察池 |
| **D 大盘+行业热度** | 指数状态、热行业榜单 | 决定"做不做"与"做什么行业" |

买入纪律（人工执行）：分仓分批；止损位≈-7%~-8%或跌破关键均线（欧奈尔）／破位坚决砍（静水）；
对了不止盈，拿到业绩增速拐点出现（静水：持有到基本面不行了再卖）。

## 7. 人工核验清单（API 无法量化，出名单后逐只确认）

财报/公告关键词（静水+欧奈尔 N 要素）：
- [ ] 供不应求 / 订单饱满 / 产线满产
- [ ] 量价齐升 / 产品涨价且下游接受
- [ ] 新产品/新服务/新市场/新应用场景放量
- [ ] 存货与应收是否健康、经营现金流可持续性细节（毛利率/净现比/现金质量已量化列示，仍须核对披露口径）
- [ ] 扩产/资本开支加速（行业景气延续）
- [ ] 行业景气度是否仍在向上（否→砍）
- [ ] 管理层增持、机构调研纪要积极、优质基金新进
- [ ] 商业模式与竞争格局：垄断性/定价权/持续性

## 8. 局限与代理说明

1. **指标口径**：净利同比为"归母净利润同比"（同花顺指标，实际 id 以运行时探测 dump 为准：`cache/probe_dump.json`）；中报 ROE 未年化口径。
2. **RS 无官方源**：用"250日超额收益 vs 沪深300 + 候选池内百分位"近似，全市场排名精度受限。
3. **机构持仓（I 要素）无数据接口**：用流通市值/成交额近似，机构认同需人工核验。
4. **N 要素的"新产品"**无法从数字判断：归入人工核验清单。
5. 前复权日K与实时快照价差>30%时以K线最新收盘为准。
6. 中报披露期（7-8月）数据逐日补齐，早期运行家数偏少属正常；表头注明报告期边界。

## 9. 每日运行

```bash
python3 projects/trend_alpha/run.py            # 每日新报告（缓存优先，1-3分钟）
python3 projects/trend_alpha/run.py --refresh-fin   # 强制重拉财务（新报告期开始后）
```
输出：`output/trend_alpha/trend_alpha_YYYY-MM-DD.md/.json`
